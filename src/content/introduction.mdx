# Evolvex — Autonomous Incident Investigation OS on SigNoz

Evolvex is an autonomous incident investigation operating system built on top of SigNoz. It correlates alerts, distributed traces, structured logs, eBPF kernel events, Kubernetes cluster changes, and CI/CD git deployments into verified, root-cause incident timelines.

## Core Capabilities

- **eBPF Socket Probes (OBI):** Zero-overhead kernel observation capturing TCP drops (`kfree_skb`), socket resets, and SYN retransmits at the network layer before application runtimes detect packet failure.
- **SigNoz Bridge:** Continuous OTLP collector stream over gRPC port 4317 with automated HMAC SHA-256 webhook ingestion.
- **CI/CD Deployment Correlation:** Pins GitHub commit SHAs and release webhooks directly onto latency inflection points with zero manual coordination.
- **Autonomous Root Cause Analysis (RCA):** Synthesizes causal graphs across traces, kernel socket drops, and Kubernetes pod evictions in under 45 seconds with 94%+ confidence.
- **SigNoz MCP Server:** Native Model Context Protocol interface exposing live telemetry query tools (`search_spans`, `get_incident_timeline`) to AI coding agents like Claude and Cursor.
- **Multi-Tenant Vault:** Strict tenant isolation at the PostgreSQL layer with Row-Level Security (RLS) and envelope encryption for all credentials.

## Getting Started

To install and run Evolvex locally or deploy on your Kubernetes cluster:
1. Deploy SigNoz with Foundry using `pnpm signoz:local:up`.
2. Connect your OpenTelemetry collector and eBPF instrumentation daemon.
3. Configure your tenant webhook secrets and explore the autonomous investigation OS.
