The Evolvex API exposes endpoints for ingesting observability webhooks, managing incident investigations, querying causal timelines, and executing Model Context Protocol (MCP) tools.

Every endpoint page in this reference features an interactive **Send** button powered by Thally, allowing you to test queries live against your development or staging deployment.

## Base URLs

| Environment | Base URL | Usage |
| :--- | :--- | :--- |
| **Production** | `https://evolvex-api.ishaandev.co.in` | Hosted customer workspaces & live webhooks |
| **Local Development** | `http://localhost:8000` | Local development via Docker / `pnpm dev` |

## API surfaces

The Evolvex API consists of four distinct surfaces:

<CardGroup cols={2}>
  <Card title="Inbound Webhooks" icon="webhook">
    Ingests fired alerts from SigNoz, git commits from GitHub, cluster changes from Kubernetes, and kernel signals from eBPF.
  </Card>
  <Card title="Investigations & Timelines" icon="flame">
    Query active incident cases, inspect multi-signal causal timelines, and fetch rule-based narratives.
  </Card>
  <Card title="Telemetry & Health" icon="activity">
    Dependency-aware deep health checks (`/health/deep`) validating SigNoz API, Redis, and database pool state.
  </Card>
  <Card title="Model Context Protocol (MCP)" icon="bot">
    Natural language telemetry tools queryable by Claude Code, Cursor, and autonomous engineering agents.
  </Card>
</CardGroup>

## Quick example: List investigations

Query your workspace's active and resolved incident cases:

```bash
curl -X GET "https://evolvex-api.ishaandev.co.in/api/investigations?limit=10&caseStatus=open" \
  -H "Authorization: Bearer ${EVOLVEX_API_KEY}" \
  -H "Content-Type: application/json"
```

Example response:
```json
[
  {
    "id": "c4a78a10-2b36-4d22-9e8a-e9012f205ab1",
    "shortId": "INV-1042",
    "title": "p99 latency spike — payments-svc",
    "status": "ready",
    "caseStatus": "open",
    "severity": "critical",
    "affectedServices": ["payments-svc", "redis-cache"],
    "createdAt": "2026-09-10T18:41:00Z"
  }
]
```
